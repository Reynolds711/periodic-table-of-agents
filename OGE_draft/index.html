Domain legend

Maturity model

Period 1: Reference
Reference agents answer questions and make trusted information easier to find.
Period 2: Assistant
Assistant agents help prepare work products, briefs, drafts, and next-step recommendations.
Period 3: Transactional
Transactional agents capture structured inputs and prepare records, requests, or evidence.
Period 4: Workflow
Workflow agents route work, coordinate handoffs, and maintain process continuity.
Period 5: Decision Support
Decision-support agents prioritize, forecast, identify risk, and recommend action.
Period 6: Cross-Organization
Cross-organization agents connect workflows across teams, systems, and partners.
Period 7: Autonomous Oversight
Autonomous-oversight agents monitor operating patterns, orchestrate exceptions, and escalate safely.

Compound patterns

Example formulas show how agents combine into workflows. Subscripts indicate the role each agent plays: 1 Inform, 2 Assist, 3 Act, 4 Orchestrate.

How to use this table

This is a draft operating map, not a product list. It keeps the same periodic-table model but narrows the content to oil and gas buyers, systems, approval points, and guardrails.

  • Use strategic priorities to find credible starting sequences.
  • Use domains to localize agent examples to real work, not generic productivity.
  • Use systems and guardrails in each detail card to shape pilots, governance reviews, and customer conversations.
