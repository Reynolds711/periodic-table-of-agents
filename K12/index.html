Maturity model

Period 1: Reference
Reference agents answer questions and make trusted information easier to find.
Period 2: Assistant
Assistant agents help prepare work products, briefs, drafts, and next-step recommendations.
Period 3: Transactional
Transactional agents capture structured inputs and prepare records, requests, or evidence.
Period 4: Workflow
Workflow agents route work, coordinate handoffs, and maintain process continuity.
Period 5: Decision Support
Decision-support agents prioritize, forecast, identify risk, and recommend action.
Period 6: Cross-Organization
Cross-organization agents connect workflows across teams, systems, and partners.
Period 7: Autonomous Oversight
Autonomous-oversight agents monitor operating patterns, orchestrate exceptions, and escalate safely.

Work IQ + Governed Action substrate

The lower series are not extra use cases; they are the hidden enterprise substrate. Work IQ gives K-12 agents permission-aware context across people, meetings, student-support history, documents, and district knowledge. Governed action constrains what agents can do through identity, least privilege, approval gates, audit logs, DLP, and human escalation.

Work IQ
What the agent understandsSIS, LMS, MTSS, IEP, attendance, family engagement, board documents, meetings, policies, and institutional memory.
Governed Action
What the agent is trusted to doRoute a follow-up, draft a family message, create a task, update a workflow, or escalate only inside approved permissions and review gates.

How to use this table

This is a strategic operating map, not a product list. It helps teams identify where agents create value, which systems they must connect to, and what guardrails are required before autonomy increases.

  • Use strategic priorities to find credible starting sequences.
  • Use domains to localize agent examples to real work, not generic productivity.
  • Use systems and guardrails in each detail card to shape pilots, governance reviews, and customer conversations.
