AI Agent Periodic Tables

Interactive frameworks to explore agent capabilities, maturity, and build pathways across industries.

How to Read It

Columns represent domains (what work is being done). Rows represent maturity (how autonomously the work is performed).

Agents → Agency

As capabilities mature—from answering questions to orchestrating workflows— AI evolves from a helper into a system that executes work across teams.

How to Use This

Start with a goal. Build from simple → transactional → orchestrated agents. Sequence matters more than scale.
