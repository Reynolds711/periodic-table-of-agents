What this asset does for ClawPilot and Scout users

This table turns ClawPilot and Scout from collections of helpful prompts into a structured skill-stacking system for modern Microsoft selling.

It gives sellers a map for capability building

Each cell represents a skill a seller can build: MSX hygiene, account strategy, territory design, prospecting, deal crafting, commercial readiness, consumption planning, renewal growth, partner motion, leadership rhythm, and more.

It shows how skills compound

The table makes progression visible. Sellers can start with basic fluency and signal reading, then stack preparation, execution, orchestration, optimization, and autonomous operating loops as their business matures.

It makes platform dependency explicit

The bottom series show what has to connect for skills to move from advice to action: MSX, MSXi, Skill Shack, Scout, Microsoft 365, Sales Copilot, Copilot, sales plays, partner systems, consumption telemetry, approval gates, audit trails, privacy, policy, and scale controls.

It starts with orchestration

The #2 element, Skills Orchestrator, is the front door: it helps a seller choose whether to run an existing ClawPilot skill, paste a Scout-ready Skill Shack recipe, combine multiple skills, or build a new atlas for a recurring motion.

Build a Skills Atlas prompt

Paste this into ClawPilot or Scout when you want to turn a role, account motion, event, or workstream into a practical skill atlas.

You are my Skills Orchestrator. Build a ClawPilot / Scout Skills Task Atlas HTML artifact for the workstream below.

Workstream or role:
[Describe the business motion, customer segment, event, account, or operating rhythm.]

Use this structure:
1. Identify the core jobs to be done and the recurring decisions.
2. Map each job to existing ClawPilot skills, Scout-ready Skill Shack recipes, and any missing skills we should build.
3. Group the skills into build order: fluency, signal reading, preparation, execution, orchestration, optimization, and governed/autonomous loops.
4. For each skill, define the trigger, required inputs, trusted sources, expected output, human approval gate, and success measure.
5. Flag sensitive data, outbound-message risks, CRM-write risks, and places where source grounding is required.
6. Produce a ClawPilot / Scout Skills Task Atlas as a polished, self-contained HTML page.
7. Include sections for: executive summary, top recurring tasks, compounded skill stacks, triggers, required inputs, trusted sources, expected outputs, owners, system dependencies, approval gates, risks, success measures, and next actions.
8. Include a visual atlas table with columns for task, trigger, compounded skill stack, recipe link or build prompt, owner, system dependencies, approval gate, success measure, and next action.
9. Include a prioritized "run first" section with the three highest-leverage skill stacks and the one missing skill we should create next.
10. Make the HTML easy to save, share, and reuse: include embedded CSS, clear headings, responsive cards or tables, and no external dependencies.
