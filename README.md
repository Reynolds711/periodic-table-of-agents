## What This Is

This is not a list of tools.

It is a **decision framework** to help leaders:

- Identify high-value AI opportunities
- Understand progression from simple to autonomous agents
- Sequence implementation logically
- Align agents to real institutional and organizational goals

---

## How to Use It

### 1. Start with a Goal

Each sector includes a goal selector, such as retention, enrollment, administrative burden, revenue growth, or secure AI adoption.

This surfaces:

- The top 5 agents
- A recommended build order
- The maturity path from workflow support to orchestration

### 2. Read the Table

- **Columns / Groups = Domains**  
  Each column represents a functional domain of work.

- **Rows / Periods = Maturity**  
  Each row represents a higher level of autonomy, integration, and impact.

- **Cells = Agents**  
  Each cell represents a specific agent pattern with a shorthand symbol, name, domain, and maturity level.

- **Bottom Bands = Core Systems and Trust Layers**  
  These represent cross-cutting infrastructure, governance, data, workflow, and trust capabilities.

### 3. Use Build Sequences

The tables emphasize a practical implementation pattern:

> Start simple → prove value → connect workflows → orchestrate across domains → govern responsibly

A well-governed early-stage agent deployed against a real workflow will usually outperform an ambitious autonomous system without clean data, ownership, or trust controls.

## Design Principles

1. Start with outcomes, not tools
2. Sequence matters more than scale
3. Maturity is as important as capability
4. Cross-domain agents drive disproportionate value
5. High-power agents require governance, data quality, and human accountability

## Why the Periodic Table?

Mendeleev did not invent new elements; he revealed structure in what already existed.

AI agents are similar:

- The capabilities exist
- The deployments are emerging
- The structure is missing

This project provides that structure.
